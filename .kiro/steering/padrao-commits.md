# Padrão de commits e de contribuição

Regras permanentes para este repositório.

## Mensagens de commit

- Formato: `tipo(escopo): descrição`
- Tipos permitidos: `feat`, `fix`, `docs`, `refactor`, `test`, `style`, `chore`
- A descrição é uma frase completa em português, em linguagem humana, clara e
  objetiva.
- Nunca começar a mensagem com travessão.
- Sem abreviações confusas. Tudo em português.
- Exemplo correto: `feat(dados): adicionar camada de dados brutos com arquivo CSV`

## Granularidade

- Cada alteração em um commit próprio e pequeno, mostrando a construção passo a
  passo.

## Higiene do repositório

- Código e mensagens de commit em português.
- Não incluir nos arquivos comentários que mencionem sistema, prompt ou
  instruções internas. O repositório contém apenas código, documentação do
  projeto e mensagens de commit.
