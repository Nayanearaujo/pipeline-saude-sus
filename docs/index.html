01 · As três camadas

02 · Aula 1

Ingestão · do arquivo para a tabela
bronze · pipeline/ingestao.py

Contagens desta seção: registro da execução original, não reprocessado nesta auditoria.

Ler os .dbc do SIH sem mudar nada

Baixo os arquivos do DATASUS (27 UFs), converto de .dbc para um parquet único e gravo no schema bronze com todas as colunas como texto. Regra da camada: nenhuma conversão, nenhuma linha descartada.

Conferência: a ingestão termina em 1.256.785 registros nas três tabelas (1.238.763 internações + 12.451 CID-10 + 5.571 municípios).

03 · Aula 2

Transformação · ler o dado ≠ confiar no dado
prata · pipeline/transformacao.py

Tipar e decodificar os códigos do SIH

Aqui mora o julgamento. O SIH guarda tudo em código: converto VAL_TOT para DECIMAL (dinheiro), DT_INTER (AAAAMMDD) para data, decodifico SEXO (1→Masculino, 3→Feminino), MORTE para booleano, e derivo a UF e a região a partir do código IBGE do município. Uma linha = uma internação (AIH).

Conferência: 1.238.234 linhas na prata (529 AIHs duplicadas excluídas; nenhuma exclusão por ausência de valor). A idade usa COD_IDADE (a unidade do SIH): bebês medidos em dias/meses agora caem em "< 1 ano", que subiu de 1,4% para 4,9% da base. No mart por estado, SP lidera com 249.866, seguido de MG (135.542), PR (85.435), BA (83.953) e RJ (78.503).

04 · Aula 3

SQL · o grão antes do SELECT
ouro · sql/marts/*.sql

Dez marts escritos em SQL, cada um respondendo uma pergunta

A camada ouro é SQL puro: cada arquivo .sql declara o grão na primeira linha e vira uma tabela. Uso GROUP BY, agregações (COUNT, SUM, AVG, MEDIAN), JOIN com os dicionários, CASE WHEN para as faixas etárias, FILTER para a mortalidade e window functions (ROW_NUMBER, RANK, SUM() OVER) com CTE e HAVING nos marts de ranking. O Python (marts.py) só executa os arquivos; a regra de negócio mora inteira no SQL.

Exemplo real: o mart que compara os estados (o coração do painel).

-- Grão do resultado: uma UF.
SELECT
    uf,
    regiao,
    COUNT(*)                                                           AS internacoes,
    ROUND(SUM(valor_total), 2)                                         AS valor_total,
    ROUND(AVG(valor_total), 2)                                         AS custo_medio,
    ROUND(MEDIAN(valor_total), 2)                                      AS custo_mediana,
    ROUND(AVG(dias_permanencia), 1)                                    AS dias_medio,
    MEDIAN(dias_permanencia)                                           AS dias_mediana,
    ROUND(100.0 * COUNT(*) FILTER (WHERE morte) / COUNT(*), 2)         AS taxa_mortalidade_pct,
    ROUND(100.0 * COUNT(*) / SUM(COUNT(*)) OVER (), 2)                 AS pct_internacoes,
    ROUND(100.0 * SUM(valor_total) / SUM(SUM(valor_total)) OVER (), 2) AS pct_valor
FROM prata.internacoes
WHERE uf IS NOT NULL
GROUP BY uf, regiao
ORDER BY internacoes DESC, uf;

Insight real: o diagnóstico que mais interna no Brasil é o parto único espontâneo (CID O800, 49.288 internações), seguido de pneumonia e infecções, exatamente o perfil do SUS.

06 · Como rodar

Do zero ao dashboard
git clone https://github.com/Nayanearaujo/pipeline-saude-sus.git
cd pipeline-saude-sus
uv sync --frozen

uv run python baixar_dados.py            # baixa o SIH-RD de abril/2026
uv run python gerar_dicionarios.py       # nomes de CID-10 e municípios

uv run python executar.py                # bronze -> prata -> ouro -> qualidade

uv run streamlit run app.py              # o dashboard
uv run pytest --cov                       # os 138 testes (cobertura 97,01%)
uv run ruff check .                       # estilo e imports
Os dados brutos não ficam no repositório (boas práticas: são grandes e reproduzíveis). O script baixar_dados.py os regenera na máquina.

07 · Engenharia e Qualidade

O que a conferência do dado revelou

Em pipelines de dados, erros de domínio e de grão não lançam exceção de sintaxe, só aparecem como número distorcido na ponta:

  • Recortes diferentes. Os CSVs consolidados contêm 1.238.234 AIHs; a série de entradas em abril/2026 soma 703.067. Essa diferença foi explicada pelo histograma local: 343.386 entradas em março/2026, 100.989 em fevereiro, 76.254 em janeiro e 14.538 antes de 2026.
  • Idade e unidade. A Prata combina IDADE e COD_IDADE. O perfil publicado contém 60.839 AIHs menores de um ano; comparações históricas antes/depois não foram reexecutadas na auditoria.
  • Descrições e proveniência. O IBGE é consultado para municípios; o CID-10 vem de um espelho público. A qualidade limita nomes ausentes a 0,1% das internações e exige descrições nos 20 primeiros diagnósticos nacionais e de mortalidade.

Por isso toda a conferência de grão, chave única e reconciliação de somas virou código executável em pipeline/qualidade.py.

Validação atual

Os dez CSVs reconciliam 1.238.234 internações e R$ 2.258.865.118,36. A atualização de descrições CID reduziu as internações sem nome de 36.736 para 76, sem alterar os demais campos. Os 138 testes passaram, com cobertura de 97,01% incluindo scripts auxiliares. A execução local da versão corrigida passou nas 37 regras, com 529 duplicadas excluídas e nenhuma exclusão por ausência de valor. A competência da Bronze é abril/2026; o histograma da Prata fecha 1.238.234 internações. O recorte mensal e o uso de mode() permanecem inalterados.
