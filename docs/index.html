Arquitetura e execução

A preparação converte os arquivos .dbc para Parquet e obtém os dicionários. A Bronze lê os três arquivos com todas as colunas como texto. A Prata declara tipos, decodifica campos e deduplica por AIH. A Ouro executa dez consultas SQL com grão explícito.

Valores financeiros usam DECIMAL(12,2). A publicação do Parquet é atômica. Ingestão e marts usam transações. Os testes cobrem falhas de escrita e preservação dos dados anteriores.

uv sync --frozen
uv run python baixar_dados.py
uv run python gerar_dicionarios.py
uv run python executar.py
uv run python exportar_painel.py
uv run python relatorio.py
uv run streamlit run app.py

Os comandos são executados na raiz do projeto. Microdados e banco não são versionados.

Indicadores e apresentação

O painel apresenta cinco cartões executivos e nove figuras. O estado selecionado altera cartões e detalhes de diagnósticos, entradas e perfil. As análises complementares de mortalidade por diagnóstico e concentração municipal permanecem identificadas como Brasil.

As métricas vêm prontas dos marts. Médias, taxas e posições não são recalculadas na interface. O relatório usa um mapa SVG completo e centralizado. O mapa interativo do Streamlit requer WebGL.

As dez perguntas planejadas incluem nove viáveis na base pública. A reinternação por pessoa ficou fora do escopo por ausência de identificador pessoal adequado.

Definições e grãos · Planejamento identificado do painel

O que a validação mostrou

A série de abril tem 703.067 entradas. As outras 535.167 se distribuem em março de 2026 (343.386), fevereiro (100.989), janeiro (76.254) e antes de 2026 (14.538). Toda a Bronze tem competência abril de 2026.

O SQL usa a competência explícita de processamento. Cada execução exige uma única competência. A versão foi conferida com os microdados locais em duas execuções do commit 4510595, com os dez marts iguais aos publicados. Datas antigas não foram classificadas como erro ou internação prolongada sem investigação.

As descrições CID foram completadas por correspondência exata, de 36.736 para 76 internações sem nome. Os sete códigos restantes foram completados por fontes oficiais complementares registradas no repositório. Os 20 primeiros diagnósticos nacionais e de mortalidade têm descrição.

Idade ignorada é preservada como desconhecida. A correção foi conferida no Parquet local sem mudar os dez marts. Mortalidade hospitalar não é mortalidade populacional. O valor registrado na AIH não é o custo econômico integral da assistência.

Testes e conferência da entrega

São 156 testes automatizados, cobertura de 97,06% e mínimo de 95% no CI. A medição inclui os scripts auxiliares. Os testes usam dados sintéticos e simulações de rede.

uv run ruff check .
uv run pytest --cov

O procedimento final executa o pipeline em uma pasta isolada, imprime os centavos e compara todos os campos dos dez marts. Também confere competências, unidades de idade e datas antigas.

Como executar a conferência local · Evidências e limites

O código atual do Streamlit contém nove gráficos e o detalhamento do perfil. A confirmação do deploy exige observar esses recursos na instância pública após seu reinício.
